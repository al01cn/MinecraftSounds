# 分类

分类功能，用于方便归纳音频文件，比如建造关卡的时候，第一关的音频都可以放到第一关里。

分类功能的按钮在音频列表的右上角，如图所示：  
![分类](/img/cg/cg.jpg)

# 如何使用分类

1. 点击「添加分类」按钮
![添加分类](/img/cg/cg_1.jpg)
2. 在弹出的对话框中输入分类名称
![添加分类](/img/cg/cg_2.jpg)
::: warning 注意
分类名称不能包含空格或特殊字符，仅允许使用小写英文字符或阿拉伯数字的组合，最好数字不要在最前面，也不要使用纯数字。
:::
3. 点击「确定」按钮，提示「创建成功」，分类就添加成功了
![添加分类](/img/cg/cg_3.jpg)
4. 可以在音频列表中下拉选择框里切换分类
![切换分类](/img/cg/cg_4.jpg)

# 使用分类的变化

1.7.10及以下版本：
/playsound mcsd.{分类名称}.{音效soundkey} @a ~ ~ ~ 10000
1.8及以上版本：
/playsound mcsd.{分类名称}.{音效soundkey} record @a ~ ~ ~ 10000

::: tip 提示
在使用分类的变化时，需要将 {分类名称} 替换为实际的分类名称，将 {音效soundkey} 替换为实际的音效soundkey。
例如：一个分类名称为 "test"，一个音效soundkey为 "my_sound"，则完整的 soundkey 为 "mcsd.test.my_sound"。
:::
