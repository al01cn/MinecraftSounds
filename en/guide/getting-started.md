# Getting Started

This guide will help you quickly get started with MinecraftSounds and create your first Minecraft music pack.

## Installing MinecraftSounds Music Pack Generator

### System Requirements

- Windows 10 or above
- 1GB memory
- 500MB available disk space

### Download MinecraftSounds Music Pack Generator

1. Go to the [Download page](/en/download) to get the latest version of the MinecraftSounds Music Pack Generator
2. Download the compressed file (e.g., MinecraftSounds.zip or MinecraftSounds.7z)
3. Extract the compressed file to your chosen directory (e.g., D:\MinecraftSounds)

::: tip Tip
Please check if the extracted contents match the image
![Extracted contents](/img/gs/gs.jpg)
:::

## Creating Your First Music Pack

### Launch MinecraftSounds Music Pack Generator

Start the application. On first launch, you will see a file format association prompt.

![Create project](/img/gs/gs_1.jpg)

Follow the prompts to associate the MinecraftSounds Music Pack Generator with the .mcsd file format.

::: tip Tip
After association is complete, you can directly double-click .mcsd files to open the program.
:::

### Create a New Project

1. Click the "New Project" button
![Create project](/img/gs/gs_2.jpg)
2. Fill in the information in the New Project window that appears
![Create project](/img/gs/gs_3.jpg)
3. After confirming the information is correct, click the "Confirm" button
![Create project](/img/gs/gs_4.jpg)
4. In the secondary confirmation dialog, click the "Create" button
![Create project](/img/gs/gs_5.jpg)
5. After the project is created, it will switch to the editing page. A "Project created successfully" dialog will appear; you can click "OK" to close it.
![Create project](/img/gs/gs_6.jpg)

### Adding Sound Effects

Now, you can start adding custom sound effects:

1. Click the "Select File" button, and in the file selection window that appears, select the audio file you want to add
![Create project](/img/gs/gs_7.jpg)
::: tip Tip
Only .ogg, .wav, .mp3, and .flac audio file formats are supported
:::
2. The added audio files will be displayed in the list below, where you can view the audio files you've added
![Create project](/img/gs/gs_8.jpg)

::: warning Note
Minecraft officially only supports .ogg format audio files. When exporting, the program will automatically convert other formats to .ogg format.
:::

### Exporting the Music Pack

When you are satisfied with your music pack, you can export it as a resource pack usable in Minecraft:

1. Click the "Export" button in the top menu
![Create project](/img/gs/gs_9.jpg)
2. Click the "Start Export" button at the bottom, and the program will begin executing according to the steps above.
![Create project](/img/gs/gs_10.jpg)
3. After a successful export, a dialog will appear; click the "OK" button to close it.
![Create project](/img/gs/gs_11.jpg)
4. Click the "Open Folder" button in the lower left corner to open the folder containing the packaged audio pack
![Create project](/img/gs/gs_12.jpg)
::: warning Tip
If the program doesn't open the folder, you can find it through the path shown after "Folder opened".  
You can also find it at: `{software directory}\_internal\app\projects\{your music pack name}\dist`
![Create project](/img/gs/gs_13.jpg)
:::

## Installing the Music Pack in Minecraft

1. Open Minecraft
2. Click "Options" → "Resource Packs"
3. Click "Open Resource Pack Folder"
4. Copy the exported .zip file to this folder
5. Return to Minecraft, your music pack should appear in the available resource packs list
6. Click the "→" button to move it to the "Selected Resource Packs" list
7. Click the "Done" button

Now, you can use your custom sound effects or music in the game!
